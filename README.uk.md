# Game Hunt Бот 🎮

Безсерверний бот, який автоматично відстежує безкоштовні роздачі ігор на популярних платформах, таких як **Epic Games**, **Steam** та **PlayStation Plus**. Він розроблений для запуску за розкладом, перевірки нових пропозицій та надсилання своєчасних, гарно відформатованих сповіщень у Telegram-канал, щоб ви ніколи не пропустили роздачу.

## Можливості

- **Моніторинг кількох платформ**: Відстежує безкоштовні ігри на Epic Games, Steam та PlayStation Plus (місячні ігри та ігри з каталогу).
- **Сповіщення в Telegram**: Надсилає зрозумілі, відформатовані повідомлення у вказаний Telegram-канал про анонси нових ігор.
- **Адміністративні команди**: Дозволяє адміністратору керувати ботом за допомогою команд у Telegram:
  - `/check`: Миттєво запускає перевірку нових роздач ігор.
  - `/stats`: Показує детальну статистику про кількість ігор, що зберігаються в базі даних.
  - `/help`: Виводить довідкове повідомлення про можливості бота та доступні команди.
- **Постійне сховище**: Використовує **Upstash (Redis)** для зберігання даних у продакшені та локальний JSON-файл для розробки, що запобігає повторним сповіщенням.
- **Безсерверне розгортання**: Створено для роботи як економічно ефективна безсерверна функція на таких платформах, як Vercel.
- **Перевірки за розкладом**: Використовує cron-завдання (налаштовані у `vercel.json`) для автоматизації періодичних перевірок нових роздач.
- **Гнучке налаштування**: Легко вмикайте або вимикайте модулі платформ та налаштовуйте поведінку бота через центральний файл налаштувань.
- **Покращена архітектура повідомлень**: Вся логіка форматування та надсилання повідомлень централізована в модулі `telegram.js`, що робить код чистішим та легшим для підтримки.

## Використані технології

- **Середовище виконання**: [Node.js](https://nodejs.org/)
- **Розгортання**: [Vercel](https://vercel.com/) (Serverless Functions)
- **База даних**: [Upstash (Redis)](https://vercel.com/marketplace/upstash)
- **Планувальник**: Vercel Cron Jobs
- **HTTP-клієнт**: [Axios](https://axios-http.com/)
- **Мова**: JavaScript (ES Modules)

## Початок роботи

### Вимоги

- Встановлені Node.js та npm.
- Токен Telegram-бота від [@BotFather](https://t.me/BotFather).
- ID Telegram-каналу/чату, куди будуть надсилатися сповіщення.
- (Для продакшену) База даних Upstash Redis (Vercel KV) та облікові дані для підключення.

### Встановлення

1.  Склонуйте репозиторій:
    ```bash
    git clone https://github.com/your-username/game-hunt.git
    ```
2.  Перейдіть до каталогу проєкту:
    ```bash
    cd game-hunt
    ```
3.  Встановіть залежності:
    ```bash
    npm install
    ```

### Налаштування

1.  **Змінні середовища**: Створіть файл `.env` у кореневому каталозі та додайте ваші дані. Для розгортання на Vercel, вам потрібно буде додати їх у налаштуваннях проєкту.

    _Щоб дізнатися ваш `TELEGRAM_ADMIN_CHAT_ID`, напишіть боту `@userinfobot` у Telegram._

    ```env
    # Облікові дані Telegram (обов'язково)
    TELEGRAM_BOT_TOKEN="ВАШ_ТЕЛЕГРАМ_БОТ_ТОКЕН"
    TELEGRAM_CHAT_ID="ID_ВАШОГО_ТЕЛЕГРАМ_ЧАТУ"

    # Облікові дані Upstash Redis / Vercel KV (обов'язково для продакшену)
    KV_REST_API_URL="ВАШ_KV_REST_API_URL"
    KV_REST_API_TOKEN="ВАШ_KV_REST_API_TOKEN"

    # --- Вебхук для ручного запуску (опціонально) ---
    # Довгий, випадковий рядок для захисту вашого вебхука
    TELEGRAM_WEBHOOK_SECRET="ВАШ_СУПЕР_СЕКРЕТНИЙ_РЯДОК"
    # Ваш особистий ID в Telegram для обмеження доступу до команд адміністратора
    TELEGRAM_ADMIN_CHAT_ID="ВАШ_ОСОБИСТИЙ_TELEGRAM_ID"
    # URL вашого проєкту на Vercel (напр., your-project-name.vercel.app)
    VERCEL_URL="your-project-name.vercel.app"
    ```

2.  **Налаштування бота**: Відкрийте `config/settings.js`, щоб увімкнути/вимкнути модулі для конкретних платформ та налаштувати інші параметри бота.
3.  **Розклад Cron**: Змініть розклад у файлі `vercel.json`, щоб визначити, як часто має виконуватися перевірка. За замовчуванням встановлено `0 18 * * *` (щодня о 18:00 за UTC).

### Налаштування команд бота

Щоб команди `/check`, `/stats` та `/help` відображалися в інтерфейсі Telegram (при введенні `/` у чаті), вам потрібно зареєструвати їх через Telegram Bot API.

1.  **Переконайтеся**, що змінна середовища `TELEGRAM_BOT_TOKEN` встановлена у вашому файлі `.env` (або `.env.local`).
2.  Відкрийте термінал у кореневій папці проєкту (`game-hunt/`).
3.  Запустіть спеціальний скрипт для встановлення команд:
    ```bash
    node scripts/setup-commands.js
    ```
4.  Ви повинні побачити повідомлення про успішну реєстрацію. Щоб зміни відобразилися, можливо, доведеться перезапустити Telegram-клієнт.

### Локальне тестування

Проєкт містить комплексний тестовий скрипт `test-all.js`, який дозволяє перевірити всю функціональність локально без необхідності розгортання.

Скрипт виконає наступні дії:

- Завантажить свіжі дані з усіх увімкнених платформ.
- Порівняє їх із даними у вашому локальному файлі `data/games.json`.
- Відобразить усі знайдені нові ігри.
- Зімітує оновлення локального файлу сховища.
- Покаже, як виглядатимуть фінальні повідомлення для Telegram.

Для запуску виконайте команду:

```bash
node test-all.js
```

### Розгортання на Vercel

1.  Запуште проєкт у Git-репозиторій (GitHub, GitLab, Bitbucket).
2.  Імпортуйте проєкт на [Vercel](https://vercel.com) та підключіть до нього сховище Vercel KV (Upstash Redis).
3.  Додайте змінні середовища з вашого `.env` файлу в налаштування проєкту на Vercel.
4.  Розгорніть проєкт. Vercel автоматично налаштує безсерверну функцію та cron-завдання на основі вашої конфігурації у `vercel.json`.
5.  **Налаштуйте Telegram Webhook (Опціонально)**: Щоб увімкнути ручну перевірку та команди адміністратора, вам потрібно зареєструвати вебхук у Telegram. Відкрийте наступне посилання у браузері, замінивши значення на ваші:
    ```
    https://api.telegram.org/bot<ВАШ_БОТ_ТОКЕН>/setWebhook?url=https://<VERCEL_URL>/api/webhook?secret=<TELEGRAM_WEBHOOK_SECRET>
    ```
    Ви повинні побачити повідомлення про успішне встановлення.

## Структура проєкту

```
game-hunt/
├── 📁 api/                   # Вхідна точка для безсерверної функції Vercel
│   ├── 📄 check-games.js     # Головний обробник (для cron-завдань)
│   └── 📄 webhook.js         # Обробник команд від Telegram (напр., /check)
├── 📁 config/                 # Файли конфігурації
│   └── 📄 settings.js        # Перемикачі модулів та налаштування бота
├── 📁 data/                  # Локальне сховище даних для розробки
│   └── 📄 games.json         # Зберігає поточні та попередні списки ігор
├── 📁 lib/                   # Основні модулі з логікою
│   ├── 📄 epic-games.js      # Логіка для отримання даних з Epic Games
│   ├── 📄 steam.js           # Логіка для отримання даних зі Steam
│   ├── 📄 ps-plus.js         # Логіка для отримання даних з PlayStation Plus
│   ├── 📄 storage.js        # Обробляє читання/запис у KV або локальний JSON
│   ├── 📄 kv.js              # Конфігурація клієнта Upstash Redis
│   └── 📄 telegram.js       # Обробляє надсилання повідомлень у Telegram
├── 📁 scripts/                # Скрипти для налаштування бота
│   └── 📄 setup-commands.js  # Скрипт для реєстрації команд бота в Telegram
├── 📄 test-all.js            # Комплексний скрипт для локального тестування
├── 📄 .env.example           # Приклад змінних середовища
├── 📄 vercel.json            # Конфігурація розгортання та cron-завдань Vercel
└── 📄 package.json           # Залежності та скрипти проєкту
```
